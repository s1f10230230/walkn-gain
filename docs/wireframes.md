# WalkingApp Simple MVP Wireframes

対象: 30–50代中心（やや高め）。読みやすさ・高コントラスト・シンプル操作を最優先。

スクリーン: Home / History / Settings（Shareはメニューのサブ）

---

## Home

```
+--------------------------------------------------+
|  Oct 28 (Tue)                                ⋯   |
|                                                  |
|              [   Goal Ring  75%   ]              |
|               12,345 歩   目標 10,000            |
|               ストリーク: 5 日                   |
|                                                  |
|             7日平均: 9,870   ベスト: 14,210      |
|                                                  |
|                 （下部）                         |
|  [ 履歴 ]   [ 設定 ]   [ ... ]（シェア/ヘルプ）  |
+--------------------------------------------------+
```

注記:
- 数字は大きく、桁区切り（例: 12,345）。
- ストリークは「目標達成日」で加算/維持。フリーズは次期。
- シェアは「…」内に格納（サブ機能）。

---

## History（履歴）

```
+--------------------------------------------------+
|  履歴                                           |
|  [ 7日 ]  [ 30日 ]                               |
|--------------------------------------------------|
|  ████  ███   ██  ████  ████  ██   █             |
|  月    火    水  木    金    土   日             |
|--------------------------------------------------|
|  ベスト: 14,210 歩（10/21）                      |
|  合計: 67,890 歩                                 |
+--------------------------------------------------+
```

注記:
- シンプルな棒グラフ。値はタップでツールチップ表示。
- 範囲切替は7日/30日のみ（MVP）。


## Share（サブ・画像生成）

```
+--------------------------------------------------+
|  シェア画像（Calm）                               |
|  サイズ: 9:16 / 1:1                               |
|--------------------------------------------------|
|  [ プレビュー ]                                   |
|   ┌──────────────────────────────────┐          |
|   │   12,345 歩                      │          |
|   │   ストリーク 5 日  ｜  目標達成  │          |
|   │   2025-10-28                      │          |
|   └──────────────────────────────────┘          |
|--------------------------------------------------|
|  [ 画像を保存 ]                                   |
+--------------------------------------------------+
```

注記:
- シェアは主導線ではなく、メニューからアクセス。
- 画像保存後はOS共有シートを任意で使用。
